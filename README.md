## English

For the latest official release and release notes, scan the WeChat QR code above to follow **我不是源神** (recommended).

You can also download the complete official application directly from [GitHub Releases](https://github.com/Wobushi-Yuanshen/WobushiYuanshen/releases) or [CNB Releases (mainland China)](https://cnb.cool/Wobushi-Yuanshen/WobushiYuanshen/-/releases). Choose the Windows x64 `YuanShenV<version>.<build>.zip` release attachment, extract the entire archive, and run `我不是源神.exe` inside the extracted folder.

This repository hosts software releases, release notes, and the official WeChat QR code. The first official release is being prepared; no release ZIP is available here yet. Download links will appear in Releases when ready. `Code → Download ZIP` and `Source code` download repository archives, which do not contain the runnable application. Use the official release attachments instead.

In the app, open **更新和反馈** (Updates and feedback) for both update channels. Select **手动检查更新** (Check for updates) at the top of the dialog to check manually. Automatic checks use the same dialog when a new official release is available. You choose whether to download and update.
